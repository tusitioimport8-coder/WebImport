# 📚 Documentación — TuSitioImport

Bienvenido a la documentación del sistema **TuSitioImport**.

Esta documentación está organizada por módulos para facilitar la navegación, el mantenimiento y la búsqueda de información.

## 📦 Módulos

### 🔐 Autenticación

Gestión de registro, inicio de sesión, cierre de sesión, usuarios, sesiones y seguridad.

➡️ [Ver documentación de Auth](./auth/README.md)

### 📦 Productos

CRUD completo de productos, incluyendo imágenes, galería, precios, categorías y middlewares.

➡️ [Ver documentación de Productos](./productos.md)

### 🛒 Carrito

Gestión del carrito de compras, cantidades, precios por nivel, descuentos y notificaciones de progreso.

➡️ [Ver documentación del Carrito](./carrito.md)

### 🏷️ Categorías

Gestión de categorías de productos, incluyendo creación, actualización y eliminación.

➡️ [Ver documentación de Categorías](./categorias.md)

### 💡 Sugerencias

Registro de interacciones del usuario con los productos y generación de recomendaciones basadas en sus intereses recientes

➡️ [Ver documentación de Sugerencias](./sugerencias.md)

### ⚙️ Configuración

Información general sobre la organización técnica y puntos de configuración documentados del sistema.
